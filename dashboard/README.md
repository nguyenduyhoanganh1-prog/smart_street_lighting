# dashboard

Trang web tĩnh (HTML/JS) đặt trên GitHub Pages, kết nối HiveMQ Cloud qua MQTT WebSocket (TLS): xem thông số và lux, điện năng tiêu thụ từng bóng (bảng + biểu đồ 24 giờ), chỉnh tay, cài đặt ngưỡng lux và thời gian sáng dần/tối dần, hiện ảnh khi có cảnh báo.
Không chứa mật khẩu MQTT trong code: người dùng nhập tài khoản khi mở trang.
